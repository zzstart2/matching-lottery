# 相亲活动摇号系统 - 网页版

这是一个使用HTML、CSS和JavaScript开发的相亲活动摇号系统网页版。该系统可以随机匹配女生和男生的号码，支持自定义号码范围、字体大小等设置。

## 功能特性

- 随机生成女生和男生号码配对
- 美观的粉蓝色渐变主题
- 配对结果动画效果
- 响应式设计，适配各种屏幕尺寸
- 自定义设置：
  - 女生和男生号码范围
  - 标题、数字和标签字体大小
- 设置自动保存到本地存储

## 使用方法

1. 在浏览器中打开index.html文件
2. 点击"开始"按钮开始随机滚动号码
3. 再次点击"停止"按钮停止滚动并选择号码
4. 系统会显示匹配结果，并有动画效果
5. 点击"重新开始"按钮可以重新进行摇号

## 设置功能

点击右上角的"设置"按钮可以打开设置面板：

1. 女生号码范围 - 设置女生号码的最小值和最大值
2. 男生号码范围 - 设置男生号码的最小值和最大值
3. 字体大小 - 可以分别设置标题、数字和标签的字号大小

所有设置会自动保存到浏览器的本地存储中，下次打开页面时自动加载。

## 技术实现

- HTML5 - 页面结构
- CSS3 - 样式和动画效果
- JavaScript - 业务逻辑和交互
- Local Storage - 存储用户设置

## 特点优势

相比原Python版本，网页版具有以下优势：

1. **无需安装** - 不需要安装Python和pygame等依赖
2. **跨平台** - 任何支持现代浏览器的设备都可以运行
3. **更好的兼容性** - 无需考虑字体问题
4. **更方便分享** - 可以部署到网络服务器上供多人使用
